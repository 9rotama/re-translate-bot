# リプレース要件

現行の無駄翻訳 bot を、Discord Interactions 方式のサーバーレス構成に置き換える。
この文書は置き換えで「何を残し、何をなくし、何を変えるか」を定める。
構成・技術選定・コマンドの応答形式などの「どう作るか」は、以降の設計タスクで決める。

## 現行構成

| 役割 | 現行 |
| --- | --- |
| Discord との接続 | discord.py（Gateway 常時接続、プレフィックス `^^` のテキストコマンド） |
| 翻訳 | GAS（`LanguageApp.translate`）を HTTP GET で呼ぶ |
| 設定の保存 | MongoDB（チャンネル単位） |
| 実行環境 | AWS EC2 t2.micro 上の Docker |

現行の bot は、翻訳を開始したチャンネルに投稿されたメッセージを削除し、再翻訳した結果を投稿者の名前とアイコン付きの埋め込みで投稿し直す。
再翻訳は「原文の言語 → 中継言語1 → … → 中継言語N → 原文の言語」の順で行う。

## 前提（決定済み）

- 今ない機能は実装しない。今ある機能を Interactions 方式で置き換える。
- 原文を表示しない設定はなくす。原文は常にスポイラーで表示する。
- 翻訳には Workers AI の `@cf/meta/m2m100-1.2b` を使う。
  - 崩れ具合とコストは検証済み。
  - 所要時間は1段あたり約1秒、10段で約10秒。

## 機能の対応表

| 現行 | 置き換え後 | 備考 |
| --- | --- | --- |
| `^^on` / `^^off` | 廃止 | `/rt` は明示的に呼び出すため、開始・終了のスイッチが不要になる |
| `^^spoil` | 廃止 | 原文は常にスポイラーで表示する |
| プレイ中ステータス表示（`^^helpでヘルプ表示`） | 廃止 | Interactions 方式は Gateway に接続しないため設定できない |
| `^^config` | `/settings show` | チャンネルの中継ルートを表示する |
| `^^l` | `/settings relay` | 中継言語を設定する。最大10言語。空白区切りの文字列を1つの引数で受け取る |
| `^^ol` | `/settings origin` | 原文の言語を設定する。1言語 |
| `^^help` | `/help` | 使い方を表示する |
| メッセージの自動再翻訳 | `/rt` | 再翻訳したいときに明示的に呼び出す |

設定まわりの3つは、`/settings` のサブコマンドにまとめる。
`/settings` と入力すると3つが候補に並ぶので、設定の操作がどこにあるかを探さずに済む。

### `/settings show`

- 呼び出したチャンネルの中継ルート（例: `ja 👉 en 👉 ja`）を表示する。
- 原文の表示/非表示の項目はなくなる。

### `/settings relay`

- 中継言語を空白区切りの文字列で受け取る（例: `en fr de`）。
- 言語数は1以上10以下。範囲外ならエラーを返し、設定を変えない。
- 言語コードが不正ならエラーを返し、設定を変えない（「言語コードの検証」を参照）。
- 設定に成功したら、更新後の中継ルートを表示する。

### `/settings origin`

- 原文の言語を1つ受け取る。
- 言語コードが不正ならエラーを返し、設定を変えない。
- 設定に成功したら、更新後の中継ルートを表示する。

### `/help`

- 各コマンドの使い方を表示する。
- 現行のヘルプにある Google 翻訳の言語コード表へのリンクは、m2m100 の対応言語を示すものに差し替える。

### `/rt`

- 受け取った文章を、呼び出したチャンネルの中継ルートで再翻訳して表示する。
- 再翻訳の結果とあわせて、原文をスポイラーで表示する。
- 中継ルートも表示する（現行の埋め込みのフッターに相当）。

## チャンネル設定

- 設定はチャンネル単位で持つ。
- 項目は中継言語と原文の言語の2つ。現行の `started` と `show_origin_text` はなくなる。
- 未設定のチャンネルでは現行と同じ既定値を使う。
  - 中継言語: `en`
  - 原文の言語: `ja`

## 言語コードの検証

- `/settings relay` と `/settings origin` で受け取った言語コードは、m2m100 の対応言語一覧と照合して bot 側で検証する。
  - 現行は GAS に試しに翻訳させ、そのエラー文言で判定している。置き換え後は翻訳を呼ばずに判定する。
- 対応言語一覧は bot 内に持つ。

## データ移行

- MongoDB の既存データは移行しない。
- 置き換え後、すべてのチャンネルは未設定（既定値）の状態から始まる。

## Discord アプリケーション

- 本番は今の bot アプリケーション（client ID `981977773277061210`）を使い続ける。招待 URL を変えないためである。
- 検証には、本番とは別の既存の開発用アプリケーション（client ID `982084046924439622`）を使う。

## 対象外

- 現行にない機能の追加。
- 現行の bot（`src/` 配下の Python コード、GAS）の保守。置き換え後に削除する（#38）。
